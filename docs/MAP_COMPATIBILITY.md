# Map compatibility

[Back to README](../README.md)

Compatibility depends on the source assets, available texture archives, PS3
native dependencies and target game revision. Successful conversion is not a
substitute for testing the saved FastFiles on a console.

Nuketown, Nuketown XMAS, Getaway and Mirage have reached gameplay in reported
console tests. Some maps retain visual defects. Havana and Shipment XMAS have
passed conversion, structural and preflight checks; these checks alone do not
establish complete visual or multiplayer compatibility. Custom private-match
startup is confirmed on the tested BLES setup.

Getaway still has reported foliage and white-effect problems. Missing source
pixels and substituted materials must be distinguished in the output reports.
The reported Raid smoke-grenade freeze has no verified fix.

For a reproducible issue, include the tool version, map name, conversion report,
job log, target region/revision and a description of the failure. Keep game
archives and executables out of public source repositories.
